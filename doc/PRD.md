# 產品需求文件（PRD）

## 1. 概述

棋塊陷阱是一款雙人對戰的棋盤變體遊戲。玩家在 8×8 棋盤上操控棋子，並使用有限的方塊與隱形炸彈來阻擋對手、創造進攻路線，先達 5 分者獲勝。

## 2. 目標使用者

- 喜歡策略棋類遊戲的繁體中文使用者。
- 適合同一裝置上的雙人面對面對戰。

## 3. 使用者故事

### US-1：移動棋子

> 身為玩家，我想要選擇我的棋子並向上／下／左／右移動一格，以便推進至對方底線得分。

**驗收條件**
- 點擊己方棋子，棋子高亮顯示。
- 可移動的相鄰格子顯示方向箭頭。
- 點擊可移動格，棋子移動至該格。
- 移動後回合結束，輪到對方。

### US-2：放置方塊

> 身為玩家，我想要在空格或隱形炸彈上放置方塊，以阻擋對手的移動路線。

**驗收條件**
- 選擇「方塊」技能後，棋盤上可放置的格子（空格或炸彈格）可點擊。
- 放置後該格顯示方塊圖示，且方塊剩餘數 -1。
- 放置後回合結束。
- 方塊用完（剩餘數 0）時無法再選擇。

### US-3：放置炸彈

> 身為玩家，我想要在空格上放置隱形炸彈，讓對手棋子踩到時被消滅。

**驗收條件**
- 選擇「炸彈」技能後，棋盤上空格可點擊放置。
- 炸彈放置後在棋盤上不可見（顯示為空格）。
- 當棋子移動至炸彈格時，棋子被消滅，該格變為爆炸殘骸（不可通行）。
- 炸彈剩餘數 -1，回合結束。
- 炸彈用完時無法再選擇。

### US-4：計分與勝利

> 身為玩家，我想要讓棋子抵達對方底線得分，先達 5 分獲勝。

**驗收條件**
- 玩家一棋子抵達最右欄（第 H 欄）得 1 分，該棋子消失。
- 玩家二棋子抵達最左欄（第 A 欄）得 1 分，該棋子消失。
- 分數達 5 分時顯示勝利彈窗。
- 側邊欄計分進度條即時更新。

### US-5：回合切換提示

> 身為玩家，我想要清楚知道當前是誰的回合。

**驗收條件**
- 側邊欄回合面板依當前玩家顯示不同顏色（玩家一藍色、玩家二紅色）。
- 回合面板顯示當前玩家的棋子圖示與名稱。
- 非當前玩家的技能格呈灰色不可點擊。

### US-6：規則說明

> 身為新玩家，我想要在遊戲開始時看到規則說明。

**驗收條件**
- 首次載入顯示規則彈窗。
- 彈窗內容列出遊戲規則重點。
- 點擊「開始遊戲」關閉彈窗進入遊戲。

## 4. 功能優先級

| 優先級 | 功能 |
|--------|------|
| P0 | 棋子移動、計分、勝利判定 |
| P0 | 方塊放置、炸彈放置與引爆 |
| P0 | 回合切換、回合面板色彩提示 |
| P1 | 計分進度條、技能格剩餘數 |
| P1 | 規則彈窗、勝利彈窗 |
| P2 | 響應式設計 |
| P2 | 棋盤座標標籤（A–H／1–8） |

## 5. 非功能需求

- **效能**：頁面載入後 1 秒內可互動。
- **相容性**：支援主流瀏覽器（Chrome、Firefox、Safari、Edge）最新版。
- **響應式**：桌面與行動裝置皆可正常遊玩。
- **無障礙**：圖片提供 alt 文字，按鈕可鍵盤操作。
