# 專案章程（Project Charter）

## 專案名稱

棋塊陷阱（Chess Blocks & Traps）

## 願景

打造一款簡潔、易學但深具策略性的雙人棋盤對戰遊戲，透過「方塊」與「隱形炸彈」機制，在傳統棋類移動基礎上增加空間控制與心理博弈層次。

## 目標

1. **核心遊戲體驗**：8×8 棋盤上雙方對戰，每回合一動作（移動棋子／放置方塊／放置炸彈），先達 5 分者勝。
2. **現代化技術棧**：以 React + Vite 打造，純前端單頁應用，部署於 GitHub Pages。
3. **繁體中文優先**：全部介面文字為繁體中文，無語言切換層。
4. **自動化部署**：推送至 `dev-001` 即自動合併、建置、部署，無需手動介入。

## 範圍

### 包含

- 8×8 棋盤雙人對戰（同機對戰）
- 三種回合動作：移動棋子、放置方塊、放置炸彈
- 計分系統（抵達對方底線得 1 分，先達 5 分勝）
- 玩家回合面板（依玩家切換顏色）
- 計分進度條、技能格剩餘數顯示
- 規則彈窗、勝利彈窗
- 響應式設計（桌面／行動裝置）
- GitHub Actions 自動部署管線

### 不包含

- 線上對戰（僅同機對戰）
- 單人 AI 對手
- 帳號系統或資料庫
- 多語言切換
- 音效或背景音樂
