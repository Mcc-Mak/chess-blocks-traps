# 軟體需求規格書（SRS）

## 1. 簡介

### 1.1 目的

本文件規格化棋塊陷阱遊戲的軟體需求，涵蓋功能性與非功能性需求。

### 1.2 範圍

本軟體為純前端單頁應用（SPA），無後端服務。所有遊戲邏輯在瀏覽器中執行。

### 1.3 定義與縮寫

| 詞彙 | 定義 |
|------|------|
| SPA | Single Page Application，單頁應用 |
| OOP | Object-Oriented Programming，物件導向程式設計 |
| ESM | ECMAScript Modules |
| Hook | React 函數式元件中的狀態邏輯封裝 |

## 2. 整體描述

### 2.1 產品視角

本軟體為獨立的前端應用，部署於 GitHub Pages。無外部 API 依賴，無資料庫。

### 2.2 使用者特性

使用者為在同一裝置前對戰的兩名玩家，熟悉滑鼠／觸控操作。

### 2.3 限制

- JavaScript（JSX），不使用 TypeScript。
- ESM 模組系統，不使用 CommonJS。
- 僅依賴 React 18 與 Vite 5。
- 部署環境為 GitHub Pages 子路徑。

### 2.4 假設與依賴

- 使用者瀏覽器支援 ES2020+ 與 CSS Grid/Flexbox。
- GitHub Pages 服務正常運作。

## 3. 功能性需求

### FR-1：遊戲初始化

- 系統應建立 8×8 棋盤。
- 玩家一棋子置於第 A 欄（每列一枚），玩家二棋子置於第 H 欄（每列一枚）。
- 每位玩家初始 3 個方塊、3 個炸彈、0 分。
- 玩家一先行。

### FR-2：棋子選擇

- 當前回合玩家可點擊己方棋子將其選取。
- 選取後棋子高亮，可移動格顯示方向箭頭。
- 再次點擊已選棋子可取消選取。

### FR-3：棋子移動

- 棋子可向上、下、左、右移動一格。
- 目標格必須為空格或隱形炸彈。
- 移動至炸彈格：棋子被消滅，該格變為爆炸殘骸（不可通行）。
- 移動至空格且抵達對方底線：得 1 分，棋子消失。
- 移動後回合結束，輪到對方。

### FR-4：放置方塊

- 當前回合玩家可選擇「方塊」技能。
- 可放置於空格或隱形炸彈格上。
- 放置後該格顯示方塊圖示，方塊剩餘數 -1。
- 放置後回合結束。
- 剩餘數為 0 時不可選擇。

### FR-5：放置炸彈

- 當前回合玩家可選擇「炸彈」技能。
- 僅可放置於空格（不可放置於已有方塊、棋子、炸彈或殘骸的格子）。
- 放置後該格在棋盤上不可見（顯示為空格）。
- 炸彈剩餘數 -1。
- 放置後回合結束。
- 剩餘數為 0 時不可選擇。

### FR-6：計分與勝利

- 玩家一底線為第 H 欄（索引 7），玩家二底線為第 A 欄（索引 0）。
- 棋子抵達底線得 1 分，棋子消失，該格變為空格。
- 分數達 `WINNING_SCORE`（5）時，該玩家獲勝。
- 顯示勝利彈窗，點擊「再來一局」重置遊戲。

### FR-7：回合面板

- 回合面板依當前玩家切換顏色（玩家一藍色、玩家二紅色）。
- 顯示當前玩家棋子圖示與名稱。
- 非當前玩家的技能格呈灰色且不可點擊。

### FR-8：計分顯示

- 側邊欄顯示雙方分數與進度條。
- 進度條寬度依 `score / WINNING_SCORE` 比例計算。

### FR-9：技能格顯示

- 每位玩家顯示方塊與炸彈兩列技能格。
- 每列顯示 `BLOCKS_PER_PLAYER`（3）個圖示。
- 已使用的圖示呈灰色。
- 當前回合玩家的技能格可點擊，選取後高亮。

### FR-10：規則彈窗

- 首次載入時顯示規則彈窗。
- 彈窗內容為繁體中文規則列表。
- 點擊「開始遊戲」關閉彈窗。

### FR-11：遊戲重置

- 點擊「再來一局」將遊戲狀態重置為初始狀態。

## 4. 非功能性需求

### NFR-1：效能

- 首頁載入至可互動時間 < 2 秒（一般網路環境）。
- 建置产物 gzip 後 JS < 60 KB。

### NFR-2：相容性

- 支援 Chrome、Firefox、Safari、Edge 最新版。
- 支援桌面與行動裝置瀏覽器。

### NFR-3：可維護性

- 遊戲引擎與 UI 完全分離（`src/game/` 無 DOM／React 依賴）。
- 引擎為不可變 OOP，每個動作回傳新實例。
- 所有顯示文字為模組層級 `TEXT` 常數。

### NFR-4：部署

- 推送至 `dev-001` 分支自動觸發合併、建置、部署。
- 使用 `GITHUB_TOKEN`，不需 PAT。
- 建置輸出使用相對路徑（`base: './'`）。
